# GitHub Repository Analyzer

A Python-based analytics application that uses the GitHub API to extract and analyze public repository information including stars, forks, contributors, and programming languages.

## Features

- Fetch public GitHub repository data
- Analyze repository statistics
- Extract programming language insights
- Export repository data into CSV format
- Error handling and API integration workflows

## Tech Stack

- Python
- GitHub API
- Pandas
- CSV Processing

## Future Improvements

- Dashboard visualizations
- Streamlit integration
- Automated reporting
